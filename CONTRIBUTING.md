# Як долучитися

Дякуємо, що хочете допомогти! Проєкт збирає графіки відключень Прикарпаттяобленерго у JSON і PNG.

## Повідомити про проблему

- **Дані не збігаються з сайтом обленерго.** Створіть issue за шаблоном «Розбіжність у даних». Додайте чергу, дату та знімок екрана з [svitlo.oe.if.ua](https://svitlo.oe.if.ua).
- **Помилка в коді чи workflow.** Створіть issue за шаблоном «Помилка».
- **Ідея.** Створіть issue за шаблоном «Пропозиція». Перед великою зміною спершу обговоріть її в issue.

Перш ніж створювати issue, перевірте відкриті issues. Можливо, про проблему вже знають.

## Внести зміни

1. Зробіть fork і склонуйте його.
2. Створіть гілку від `main` зі змістовною назвою: `fix/half-hour-rounding`, `feat/new-image`.
3. Встановіть залежності:
   ```bash
   npm ci
   npx playwright install chromium
   ```
4. Внесіть зміни і запустіть перевірки:
   ```bash
   npm test
   npm run fetch
   npm run render
   ```
5. Не комітьте `data/`, `raw/` та `images/`. Ці файли оновлює workflow.
6. Відкрийте pull request у `main` і заповніть шаблон.

## Правила

- **Сумісність.** Формат `data/ivano-frankivsk.json` має лишатися сумісним з [outage-data-ua](https://github.com/Baskerville42/outage-data-ua). Не змінюйте назви та типи наявних полів.
- **Тести.** Нова логіка перетворення в `scripts/lib/` має мати тести в `tests/`.
- **Стиль.** Пишіть код у стилі наявного: ESM, Node.js 22+, без зайвих залежностей.
- **Коміти.** Пишіть короткі повідомлення у форматі [Conventional Commits](https://www.conventionalcommits.org/): `fix: …`, `feat: …`, `docs: …`.

Участь у проєкті означає згоду з [Кодексом поведінки](CODE_OF_CONDUCT.md).
