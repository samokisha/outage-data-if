# Політика безпеки

## Підтримувані версії

Підтримується лише поточний стан гілки `main`.

## Як повідомити про вразливість

Не створюйте публічний issue.

1. Відкрийте вкладку [Security → Report a vulnerability](https://github.com/samokisha/outage-data-if/security/advisories/new).
2. Опишіть проблему, кроки для відтворення та можливий вплив.

## Що входить у сферу

- Скрипти в `scripts/` та workflow у `.github/workflows/`.
- Ризики підміни даних чи зображень у `data/`, `raw/` та гілці `images`.

Точність самого графіка залежить від обленерго. Розбіжності з офіційним сайтом — це не вразливість. Для них є шаблон issue «Розбіжність у даних».
